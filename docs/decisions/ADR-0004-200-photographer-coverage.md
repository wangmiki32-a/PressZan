# ADR-0004：以 200 位摄影师覆盖作为每日完成条件

> 修订说明：本 ADR 的跨日恢复边界已由 [ADR-0006](ADR-0006-cross-day-active-run.md) 替代；200 位覆盖合同保持不变。

- 状态：Accepted
- 日期：2026-08-17
- 覆盖：ADR-0002 中“每日恰好 100 个确认点赞”和 verified 第二赞配额

## 背景

固定点赞数会把已点赞作品、不可读作品和候选质量差异隐藏在任务结果中。新的业务目标要求每次运行接触固定数量的摄影师，但允许实际点赞数随第一张作品状态变化。

## 决定

未来新运行以当日恰好 200 位不同摄影师完成处理为完成条件。每位只检查第一张作品；确认未点赞时点赞并评论 `👍👍👍`，已点赞或不可读时记录跳过。覆盖从点赞和跳过事件的摄影师并集确定性重建，不增加可手工修改的计数器。

历史 sealed run 的完成状态保持有效，不迁移、不重写。Dashboard 将覆盖作为进度，点赞和评论作为结果。

## 后果

- 任务可能以少于 200 个点赞完成。
- 单日不再产生同一摄影师第二赞，selector 配额改为 200 个首触达候选。
- 候选不足时任务必须以未完成状态封存，不能降低 200 位目标。
- 页面互动时间和平台风险可能增加，既有 CAPTCHA、限频和状态不明硬停止规则继续优先。

## 验证

Selector、CLI、analytics、Dashboard 和 skill contract 测试共同覆盖唯一覆盖计数、精确完成边界、历史兼容与评论规则。
